# מסך זמני שבת וחגים לטלוויזיה

דף יחיד שמוגש משרת nginx ומוצג על טלוויזיה חכמה בחצר. מציג ברכה, פרשת השבוע,
תאריך עברי, שעון חי וזמני כניסת/יציאת השבת — בגדלים שנקראים ממרחק של כ-20 מטר
על מסך 160 אינץ'.

מקור העיצוב הוא קובץ `.dc.html` שנוצר ב-Claude Design. `build.py` הופך אותו
לדף עצמאי שרץ בלי תלות בשום שירות חיצוני.

---

## הרצה על מכונה חדשה

```bash
git clone git@github.com:ohad2606/shabat_times_tv.git ~/tv-src
cd ~/tv-src

sudo mkdir -p /var/www/tv
sudo chown "$USER" /var/www/tv
cp deploy/_reload.js /var/www/tv/_reload.js        # לא נוצר אוטומטית

sudo cp deploy/nginx-tv-display.conf /etc/nginx/sites-available/tv-display
sudo ln -s /etc/nginx/sites-available/tv-display /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

./publish.sh
```

הדף יהיה זמין ב-`http://<כתובת-השרת>/tv/`. הכתובת `/` מפנה לשם אוטומטית,
כדי שאפשר יהיה להקליד בטלוויזיה רק את ה-IP.

דרישות: `python3` עם `Pillow`, ו-`nginx`. `node` נדרש רק כדי לחדש את טבלת
הפרשות (ראו למטה).

**פורט 80 בלבד, ללא HTTPS.** אם הדפדפן משדרג אוטומטית ל-`https://` החיבור
ייכשל — צריך להקליד `http://` במפורש.

## מבנה

| קובץ | תפקיד |
|---|---|
| `שבת וראש השנה.dc.html` | מקור העיצוב מ-Claude Design. **כאן עורכים תוכן.** |
| `build.py` | הופך את המקור לדף עצמאי ב-`dist/` |
| `publish.sh` | בנייה + פרסום בפקודה אחת |
| `support.js`, `image-slot.js` | ה-runtime של Claude Design |
| `vendor/` | React 18.3.1 UMD, מאומת מול ה-SRI שב-`support.js` |
| `fonts/` | Frank Ruhl Libre ו-Assistant, עברית ולטינית |
| `backgrounds/` | ארכיון תמונות רקע לפי חג |
| `bg.png` | התמונה הפעילה — העתק של אחת מ-`backgrounds/` |
| `parasha.json` | טבלת פרשות עד 2038, נוצרת ע"י `gen_parasha.mjs` |
| `deploy/` | תצורת nginx, סקריפט הפרסום, סקריפט הרענון, דף ממתין |

`dist/` נבנית מחדש בכל הרצה ואינה בריפו. **אין טעם לערוך אותה.**

## החלפת תמונת רקע

```bash
cp backgrounds/sukkot.png bg.png
./publish.sh
```

הבנייה מזהה פורמט לפי magic bytes ולא לפי סיומת (קובץ בשם `.jpg` שהוא בעצם
PNG יעבוד), ופוסלת קובץ חתוך במקום להעלות תמונה שבורה לאוויר.

## מתגים ב-`build.py`

| מתג | ברירת מחדל | מה הוא עושה |
|---|---|---|
| `THEME` | `"light"` | `light` = טקסט פחם וברונזה על תמונה בהירה. `dark` = שמנת וזהב על תמונה כהה. |
| `BG_OPACITY` | 1.0 ב-light | עוצמת התמונה. `python3 build.py 0.6` דורס לריצה אחת. |
| `DISTANCE_MODE` | `True` | הגדלת הטיפוגרפיה לצפייה מ-20 מטר |
| `SHOW_VERSE` / `VERSE` | פעיל | הפסוק המעוטר מתחת לזמנים |
| `SHOW_YOM_KIPPUR` | `False` | בלוק זמני תפילה ידניים. ראו `YOM_KIPPUR` לעדכון תאריכים ושעות. |

## מה הבנייה עושה, ולמה

ארבע הבעיות שבגללן קיים `build.py` ולא מגישים את קובץ העיצוב ישירות:

**התלויות החיצוניות.** ה-runtime מושך React מ-unpkg והעיצוב מושך גופנים
מ-Google. שניהם מוגשים עכשיו מהשרת עצמו, כך שהתצוגה לא נופלת אם שירות חיצוני
לא זמין.

**`oklch()`.** כל צבעי העיצוב כתובים ב-oklch, שנתמך רק מ-Chromium 111 (2023).
דפדפני טלוויזיות חכמות מבוססים על גרסאות ישנות בהרבה ומתעלמים מהצהרה כזו —
כלומר המסך היה יוצא שחור. הבנייה מוסיפה לכל צבע גרסת sRGB שקולה לפניו.

**גודל הטקסט.** בעיצוב המקורי אפילו הזמנים עצמם היו על יחס של 1/199 ממרחק
הצפייה, כלומר בקושי קריאים. `DISTANCE_MODE` מגדיל אותם לכ-1/104 ומכווץ את
הפריסה בהתאם.

**ערכת צבעים.** `THEME = "light"` הופך כל צבע לפי תפקידו: טקסט בהיר לפחם, זהב
לברונזה (זהב על לבן נכשל בניגודיות), וכל ההצללות הכהות לווילונות לבנים.

## אזהרות

**אם מושכים מחדש את העיצוב מ-Claude Design** — קובץ המקור מגיע עם override
קבוע לזמני הכניסה והיציאה. הקוד שם מחשב הפרש מול אותו ערך שהוא מוחל עליו, שני
האיברים מתבטלים, והתוצאה קפואה על אותה שעה **לנצח**, בלי קשר לעיר או לעונה.
`build.py` מנטרל אותו (ראו `TIMES`). בלי הנטרול, שינוי העיר לא משפיע כלל.

**טבלת הפרשות מגיעה עד 2038.** לחידוש:

```bash
npm install @hebcal/core
node gen_parasha.mjs 12 > parasha.json
```

הטבלה בלוח **ארץ ישראל**, שנבדל מלוח חו"ל בחלק מהשנים.

**זיהוי חגים חלקי.** הלוגיקה של העיצוב מזהה שבת וראש השנה בלבד. בערב סוכות או
פסח הזמן יוצג נכון, אבל התווית תאמר "כניסת השבת" ולא תזכיר את החג.

**הדף ציבורי.** כל מי שמגיע לכתובת רואה אותו, כולל שם המשפחה והזמנים.

## כיבוי והדלקה

```bash
sudo rm /etc/nginx/sites-enabled/tv-display && sudo systemctl reload nginx   # כיבוי
sudo ln -s /etc/nginx/sites-available/tv-display /etc/nginx/sites-enabled/ \
  && sudo systemctl reload nginx                                             # הדלקה
```

זה ה-server block היחיד, ולכן בכיבוי nginx מפסיק להאזין לפורט 80 לגמרי.

## רענון אוטומטי

nginx מזריק את `_reload.js` לכל דף שמוגש תחת `/tv/`. הסקריפט בודק כל 10 שניות
מונה גרסה שמתעדכן בכל פרסום, ומרענן את הדף כשהוא משתנה — כך שטלוויזיה פתוחה
מתעדכנת לבד, בלי לגעת בשלט.
